# Lunara Mobile App

React Native mobile application for Lunara using Expo.

## Getting Started

### Installation
```bash
npm install
# or
yarn install
```

### Development
```bash
npm start
```

This will start the Expo development server.

#### Run on Android
```bash
npm run android
```

#### Run on iOS
```bash
npm run ios
```

#### Run on Web
```bash
npm run web
```

### Testing
```bash
npm test
```

## Requirements

- Node.js 16+
- Expo CLI: `npm install -g expo-cli`
- Android Studio (for Android development)
- Xcode (for iOS development on macOS)

## Project Structure

- `app/` - Navigation and screens
- `app.json` - Expo configuration
- `package.json` - Dependencies and scripts
